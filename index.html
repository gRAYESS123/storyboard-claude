How it works

One command. Three phases. Zero timeline editing.

Every phase writes a plain file you can read and tweak, so you can stop, edit, and pick up where you left off.

  1. 1

    Plan & script

    Point it at a URL, PDF, doc, or text. Claude picks a narrative shape, maps an emotional arc across the beats, and writes narration timed to your target length — concept.md and script.md.

  2. 2

    Voice & animate

    Generate the voice-over with a free neural voice (or ElevenLabs), then Claude acts as the animator — choosing entrances, transitions, and word-synced hits for every beat in storyboard.html.

  3. 3

    Audit & render

    Preview it in your browser, run the built-in audit to catch broken or lifeless beats, then render a finished MP4 with headless Chromium and ffmpeg.

Features

A motion studio inside Claude Code

Scripting, choreography, narration, and rendering — the parts that used to take a team and a week.

Claude is your animator

It explores creative directions, picks one, and choreographs each beat using the 12 principles of animation — a focal entrance, an atmospheric layer, a quiet breath where the story needs it.

A real motion engine

110+ animation presets, spring physics, staggered cascades, chained sequences, camera dollies with parallax depth, shared-element morphs, and 20+ cinematic slide transitions.

Charts that draw themselves

Bar grows, donut sweeps, line draws, comparison bars, and counters that animate on the audio clock — so every number lands exactly as it's said.

Voice-over, your way

A free neural voice with no API key, voiced beat by beat so slide changes land exactly — or ElevenLabs for premium voices. Word timestamps drive per-word visual hits.

Characters & dazzle

Rig your own mascot with moods, gestures and gaze in the built-in rigger. Add confetti, fireworks, badges and 20+ other celebration effects, or pull from a curated 100+ Lottie index.

16:9 and 9:16, rendered to MP4

Horizontal for YouTube and the web, vertical for Reels, TikTok and Shorts. Or use adopt mode to narrate an existing HTML page without touching its styles.

Install

Up and running in four steps

You'll need Claude Code and Python 3.9 or newer.

  1. 1 Download and unzip into your skills folder

    Download storyboard-skill.zip ~2 MB

    macOS / Linux

    unzip storyboard-skill.zip -d ~/.claude/skills/

    Windows (PowerShell)

    Expand-Archive storyboard-skill.zip -DestinationPath $HOME\.claude\skills

  2. 2 Install the render tools

    python -m pip install playwright imageio-ffmpeg numpy edge-tts
python -m playwright install chromium

    Optional: python -m pip install elevenlabs and set ELEVENLABS_API_KEY for premium voices.

  3. 3 Check your setup

    python "$HOME/.claude/skills/storyboard/doctor.py" --smoke

    Tells you exactly what's missing and how to fix it, then renders a two-second test video.

  4. 4 Make your first video

    In Claude Code:

    /storyboard https://your-page.com

    Try --aspect 9:16 for vertical, --duration 60s to set the length, or /storyboard adopt page.html to narrate an existing page.

FAQ

Questions, answered

What do I need to use it?

Claude Code, Python 3.9 or newer, and a few free Python packages for rendering — Playwright with Chromium, imageio-ffmpeg (bundles its own ffmpeg), and edge-tts for the free voice. Run doctor.py and it will tell you what's missing.

Is it really free?

Yes. The skill is a free download and runs inside your own Claude Code plan. The built-in voice needs no API key. ElevenLabs is optional and bills your own ElevenLabs account.

What can I turn into a video?

A web page URL, a PDF, a Word or Markdown document, pasted text, or an existing HTML page or deck. Adopt mode narrates an existing page as-is, without changing its styles.

What do I get at the end?

A project folder: the plan (concept.md), the narration (script.md), a playable animated storyboard.html, the voice-over MP3, and a rendered MP4 in 16:9 or 9:16. Edit any file and re-render.

Can I change the script or the timing?

Yes — everything is plain text. Edit the narration and regenerate the voice, or open the deck in your browser and use the built-in calibration keys to retime slides by ear. Sample-accurate timing from a DAW (via AAF export) is supported too.

Where does my content go?

Claude Code processes your source under your own plan. The free voice sends the narration text to Microsoft's online text-to-speech service; ElevenLabs, if you choose it, receives the narration text. Animation and rendering happen entirely on your machine.

Can I use the videos commercially?

The visuals and the bundled sound effects are yours to use. For narration, check the terms of the voice provider you pick — ElevenLabs' paid plans cover commercial use; the free voice is best for drafts and personal projects.
